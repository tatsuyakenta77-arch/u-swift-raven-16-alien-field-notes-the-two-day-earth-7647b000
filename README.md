An alien tourist's one-line review of planet Earth: **"Five stars. The locals bag their pets' droppings and carry them home like treasure, then complain the planet is dirty. Would visit again."**

A genuine field note, not a generic "humans are weird" gag: the observation is specific and true (people scoop their dogs' droppings into little bags and carry them home), and the joke is the alien's misreading — the bags look like treasure, so the locals must prize the stuff, yet they still blame the planet for being dirty. One joke, landed once, with the punch at the end; a five-star verdict up front and "Would visit again" as the closing remark, like a real tourist review.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
